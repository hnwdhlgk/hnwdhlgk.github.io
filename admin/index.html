基本信息

普通用户注册/登录/发布需要部署 Cloudflare Worker。部署后将 Worker 地址填入上方。

外观与背景

留空则使用默认浅色背景。建议 1920×1080 以上。上传的图片保存到仓库 assets/ 目录。

横幅按钮

自定义主页顶部横幅的按钮，可增减、修改文字和跳转链接。链接以 # 开头则滚动到页面对应位置，否则打开新标签页跳转。

官方渠道

可自定义渠道名称、上传图标图片。点击「新增渠道」可添加更多。

联系方式自动转换规则

普通用户发布时无需填写超链接，系统自动根据以下规则转换。例如：字符「@」+ 前缀「https://t.me/」，输入 @hainanguanli 自动变为 https://t.me/hainanguanli 的可点击链接。

多频道抓取设置

支持配置多个Telegram频道，每个频道使用独立的Bot Token。Bot需设为对应频道的管理员。

今日在岗老师（多频道）

监控多个频道最新消息中的按钮，自动显示在主页「今日在岗老师」区域。Bot需设为对应频道管理员。

抓取指定链接 / 监控指定频道

支持两种输入：①具体消息链接（如 https://t.me/hnwdhlgk/123）抓取单条消息；②频道主页链接（如 https://t.me/hnwdhlgk）自动抓取该频道最新消息。私有频道需配置Bot Token。

抓取预览 确认无误后点击发布

标签映射规则

设置抓取到的 #标签 对应到网站的分类。例如 #10p 映射到某个三级分类，#海口 映射到二级分类，#嫩妹 作为自定义标签。

抓取标签映射类型映射值操作

频道内容转发

设置源频道/群组，自动将内容1:1复制或按标签映射后转发到目标频道/群组。目标频道的Bot需设为管理员。

可独立设置源和目标，或留空使用上方转发任务配置。1:1复制包含超链接、图片、视频、文本格式。
