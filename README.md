# hnwdhlgk.github.io

纯 GitHub Pages 无服务器版本。

1. 将 ZIP 解压后的全部内容上传到 `hnwdhlgk/hnwdhlgk.github.io` 仓库根目录。
2. Settings → Pages → Source → GitHub Actions。
3. 等待 Actions 完成。

主页：https://hnwdhlgk.github.io/
后台：https://hnwdhlgk.github.io/admin/

后台使用 GitHub Fine-grained Personal Access Token，仅建议授予本仓库 Contents: Read and write 权限；Token 只保存在管理员浏览器中。
